# Tetris AT

Tetris AT 是一款免费的 Windows 俄罗斯方块 AI 训练工具，支持 AI 对战、开局模板练习、路线提示和演示。

本仓库仅用于发布说明、许可声明与官方测试版下载，**不包含游戏源码**。维护者：miaha。

## 下载与启动

**[下载 v0.25.0-test.1 测试版（Windows x64）](https://github.com/linsola/Tetris-AT-Releases/releases/tag/v0.25.0-test.1)**

1. 在发布页的 **Assets** 中下载 `Tetris-AT-v0.25.0-test.1-Windows-x64.zip`。
2. 完整解压到有写入权限的本地文件夹，保留所有文件和子文件夹。
3. 双击 `Tetris AT v0.25.0.exe`。不要在 ZIP 内直接运行，也不要只复制 EXE。

目标系统为 **64 位 Windows 10 / Windows 11**；不提供 32 位或原生 ARM64 版本。无需另外安装 Microsoft Visual C++ Runtime。并非所有硬件、驱动和系统环境都已测试。

发布页的 `Source code (zip)` / `Source code (tar.gz)` 是 GitHub 自动提供的**本说明仓库**快照，不是游戏安装包，也不包含私有游戏源码。
