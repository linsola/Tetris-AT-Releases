# Tetris AT

Tetris AT is a free Windows Tetris AI training app featuring AI opponents, opener practice, placement hints, and demos.

This repository contains release documentation, license notices, and official test-build downloads only. **It does not contain the game source code.** Maintained by miaha.

## Download and launch

**[Download v0.25.0-test.1 (Windows x64)](https://github.com/linsola/Tetris-AT-Releases/releases/tag/v0.25.0-test.1)**

1. Download `Tetris-AT-v0.25.0-test.1-Windows-x64.zip` from **Assets** on the release page.
2. Extract the complete archive to a writable local folder, keeping all files and subfolders together.
3. Double-click `Tetris AT v0.25.0.exe`. Do not run it from inside the ZIP or copy only the EXE.

The build targets **64-bit Windows 10 and Windows 11**. It is not a 32-bit or native ARM64 build. No separate Microsoft Visual C++ Runtime installation is required. Not every hardware, driver, or system configuration has been tested.

GitHub's automatically generated `Source code (zip)` / `Source code (tar.gz)` downloads are snapshots of **this documentation repository**. They are not game packages and do not contain the private game source code.

## Test-build notes

- Test builds are marked **Pre-release**. Each update uses a distinct version number; newer releases do not automatically overwrite earlier ones.
- The executable is not digitally signed, so Windows may show an unknown-publisher warning. Verify the download source and the included SHA256 checksum. Do not disable antivirus protection.
- Saves, settings, logs, and replays are stored in the game folder. Back up your data before updating, and extract each new version to a separate folder.
- When reporting an issue, include the version, operating system, reproduction steps, and a seed or screenshot where relevant. Remove personal information before posting publicly. There is no need to upload your entire game folder or personal saves.
- Automated tests do not guarantee compatibility with every device. Controls, visuals, and the gameplay experience still need player testing.
