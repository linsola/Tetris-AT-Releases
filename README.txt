Tetris AT v0.25.0 - Public Test Build

Quick start
1. Extract the complete ZIP archive to a writable local folder.
2. Keep all included files and folders together.
3. Run "Tetris AT v0.25.0.exe".

Supported systems
- 64-bit Windows 10 and Windows 11.
- No separate Microsoft Visual C++ Runtime installation is required.
- This is an x64 build, not a 32-bit or native ARM64 build.
- A Noto CJK font is included for English/Japanese/CJK text on different Windows language editions.
- Compatibility is targeted at Windows 10/11; not every hardware/driver combination has been tested.

Security notice
- This test executable is not digitally signed. Windows may show an unknown-publisher warning.
- Verify the download source before running. Do not disable antivirus protection.

User data
- Saves, settings, progress, logs, and replays are stored inside this folder.
- Do not run the game directly from inside the ZIP archive.

This is a test build. Back up important saves before replacing the folder with a newer build.
The previously observed intermittent rapid-save failure has been fixed by retrying
temporary file-access conflicts. Persistent errors can still prevent saving;
confirm that a save succeeded before exiting.
